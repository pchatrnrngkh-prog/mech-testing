4.1

บทนำ: ของไหลคืออะไร

🧭 สาระสำคัญ

ของไหล (Fluid) คือสสารที่เมื่อมีความเค้นเฉือนมากระทำ จะเสียรูปร่างอย่างต่อเนื่องไม่หยุด การเสียรูปร่างอย่างต่อเนื่องนี้เรียกว่า "การไหล"

สสารมี 3 สถานะ คือ ของแข็ง ของเหลว และแก๊ส มีเพียงของเหลวและแก๊สเท่านั้นที่ไหลได้ ของเหลวและแก๊สจึงเป็นของไหล ส่วนของแข็งไม่ใช่

คุณสมบัติที่เรียนในบทนี้: ① ความหนาแน่น ② น้ำหนักจำเพาะ ③ ปริมาตรจำเพาะ ④ ความถ่วงจำเพาะ (และความถ่วง API)

🎯 เรียนจบแล้วต้องทำได้

  • ความรู้บอกความหมายของคุณสมบัติต่าง ๆ ของของไหลได้
  • ทักษะคำนวณเกี่ยวกับคุณสมบัติต่าง ๆ ของของไหลได้
  • ทักษะใช้เครื่องมือทดสอบคุณสมบัติของของไหลได้ และคำนวณผลการทดสอบได้
  • เจตคตินำความรู้เรื่องคุณสมบัติของของไหลไปปรับใช้ในชีวิตประจำวันได้

ของแข็ง กับ ของไหล ต่างกันอย่างไรเมื่อโดน "แรงเฉือน"

แรงเฉือนคือแรงที่ดันขนานไปกับผิว เหมือนเอามือถูไปบนผิวโต๊ะ ลองกดปุ่มด้านล่าง แล้วดูเส้นสีชมพูที่ขีดไว้ในเนื้อสาร

💡 จำง่าย ๆของแข็งโดนแรงเฉือนแล้วเอียงไปนิดหนึ่งแล้วหยุด (ปล่อยแรงก็เด้งกลับ) แต่ของไหลเสียรูปไปเรื่อย ๆ ไม่หยุด ตราบที่ยังมีแรงอยู่ นั่นคือ "การไหล" เช่น น้ำมันเครื่องในเครื่องยนต์ที่ถูกลูกสูบเฉือนตลอดเวลา

ของเหลว กับ แก๊ส ต่างกันอย่างไรเมื่อโดน "อัด"

ของเหลวและแก๊สอยู่ภายใต้ความดันเดียวกัน แต่ยุบตัวไม่เท่ากัน ลองเลื่อนแรงกดกระบอกฉีดยาทั้งสองอันที่อุดปลายไว้

สถานะของสสารไหลได้หรือไม่เป็นของไหลหรือไม่ยุบตัวตามความดันหรือไม่
🧊 ของแข็งไม่ไหลไม่ใช่–
💧 ของเหลวไหลได้ใช่ยุบน้อยมาก จนถือว่าไม่ยุบตัว (ของไหลที่ไม่ยุบตัวตามความดัน)
💨 แก๊สไหลได้ใช่ยุบตัวได้มาก (ของไหลที่ยุบตัวตามความดัน)
🗺️ แผนที่บทเรียนความหนาแน่น (4.2) → น้ำหนักจำเพาะ (4.3) → ปริมาตรจำเพาะ (4.4) → ความถ่วงจำเพาะและความถ่วง API (4.5) → ห้องทดลองเสมือนใบงาน 4 ตอนที่ 1 (ชั่ง-ตวง) และตอนที่ 2 (ไฮโดรมิเตอร์)

4.2

ความหนาแน่น (Density)

ความหนาแน่น คือ มวลสารต่อหนึ่งหน่วยปริมาตรของสารนั้น ๆ บอกว่าสารนั้น "อัดแน่น" แค่ไหน ปริมาตรเท่ากัน สารที่หนาแน่นกว่าจะมีมวลมากกว่า

ρ = mV
ρ (โร) = ความหนาแน่นของสาร (kg/m³) · m = มวลของสาร (kg) · V = ปริมาตรของสาร (m³)

หอคอยของเหลว: ของเหลวที่หนาแน่นน้อยกว่าลอยอยู่ข้างบน

กดเทของเหลวลงในแก้วทีละชนิด เรียงลำดับแบบไหนก็ได้ แล้วดูว่าสุดท้ายแต่ละชนิดไปอยู่ชั้นไหน จากนั้นลองหย่อนวัตถุลงไป

เทของเหลว (ตัวเลขคือความหนาแน่นโดยประมาณ kg/m³)
หย่อนวัตถุ
แก้วยังว่างอยู่ ลองเทของเหลวชนิดใดก็ได้

ในการทำจริงต้องเทช้า ๆ ไหลตามขอบแก้ว ของเหลวบางคู่ (เช่น น้ำกับน้ำยาล้างจาน) ค่อย ๆ ผสมกันได้ ภาพนี้แสดงกรณีที่ไม่ผสมกัน

แปลงหน่วยปริมาตรให้เป็น m³ ก่อนคำนวณทุกครั้ง

ในชีวิตประจำวันเราใช้หน่วยปริมาตรหลายหน่วย เช่น cc, ml, ลิตร (Litre), cm³ แต่การคำนวณด้านของไหลใช้ m³ ถ้าโจทย์ให้หน่วยอื่นต้องแปลงเป็น m³ ก่อน โดยใช้ความสัมพันธ์

1 m³ = 1,000 Litreลิตร → m³ ให้ หาร 1,000 (× 10⁻³)
1 Litre = 1,000 cccc → ลิตร ให้หาร 1,000
1 cc = 1 ml = 1 cm³cc, ml, cm³ → m³ ให้ × 10⁻⁶

4.3

น้ำหนักจำเพาะ (Specific Weight)

น้ำหนักจำเพาะ คือ น้ำหนักของสารต่อหนึ่งหน่วยปริมาตรของสารนั้น ๆ ต่างจากความหนาแน่นตรงที่ใช้ "น้ำหนัก" (แรงที่โลกดึง หน่วยนิวตัน) แทน "มวล" (เนื้อสาร หน่วยกิโลกรัม)

γ = wV
γ (แกมมา) = น้ำหนักจำเพาะ (N/m³) · w = น้ำหนักของสาร (N) · V = ปริมาตร (m³)
γ = ρ · g
ที่มา: w = m·g แทนในสูตรซ้าย → γ = m·gV = mV·g = ρ·g
g = ความเร่งเนื่องจากแรงโน้มถ่วงของโลก = 9.81 m/s²

ชั่งของเหลว 1 ลูกบาศก์เมตร บนโลก และบนดวงจันทร์

⚠️ สังเกตย้ายไปดวงจันทร์ ความหนาแน่นเท่าเดิม (เนื้อสารเท่าเดิม) แต่น้ำหนักจำเพาะลดลง เพราะแรงดึงดูดน้อยลง ในบทเรียนนี้ใช้ g = 9.81 m/s² เสมอ
4.4

ปริมาตรจำเพาะ (Specific Volume)

ปริมาตรจำเพาะ คือ ปริมาตรของสารต่อหนึ่งหน่วยมวลของสารนั้น ๆ ตอบคำถามว่า "สาร 1 กิโลกรัม กินที่เท่าไร" ซึ่งกลับด้านกับความหนาแน่น

VS = Vm
VS = ปริมาตรจำเพาะ (m³/kg) · V = ปริมาตร (m³) · m = มวล (kg)
ในใบงานใช้ตัว v (วีตัวเล็ก) แทน VS
VS = 1ρ หรือ ρ = 1VS
ที่มา: ρ = mV ดังนั้น 1ρ = Vm = VS
ปริมาตรจำเพาะกับความหนาแน่นเป็นส่วนกลับซึ่งกันและกัน

สาร 1 กิโลกรัม กินที่เท่าไร (กดเลือกสาร)

ปริมาตรจำเพาะใช้มากกับแก๊สและไอน้ำ (เช่น ในวิชาเทอร์โมไดนามิกส์) เพราะปริมาตรของแก๊สเปลี่ยนไปตามความดันและอุณหภูมิมาก

4.5

ความถ่วงจำเพาะ (Specific Gravity) และความถ่วง API

ความถ่วงจำเพาะ คือ อัตราส่วนระหว่างความหนาแน่นของสาร กับความหนาแน่นของน้ำ (หรืออัตราส่วนระหว่างน้ำหนักจำเพาะของสาร กับน้ำหนักจำเพาะของน้ำ) บอกว่าสารนั้นหนักเป็นกี่เท่าของน้ำ

s.g. = ρfρw หรือ s.g. = γfγw
s.g. = ความถ่วงจำเพาะ (ไม่มีหน่วย เพราะหน่วยบนกับล่างตัดกันหมด) · คนไทยนิยมเขียนว่า ถ.พ.
ρf, γf = ความหนาแน่น / น้ำหนักจำเพาะของสาร · ρw = 1,000 kg/m³ และ γw = 9,810 N/m³ (ของน้ำ)
s.g. น้อยกว่า 1เบากว่าน้ำ เทลงน้ำจะลอย เช่น น้ำมันเกือบทุกชนิด
s.g. = 1.000คือน้ำ ใช้เป็นตัวเทียบ
s.g. มากกว่า 1หนักกว่าน้ำ เทลงน้ำจะจม เช่น น้ำเกลือ กลีเซอรีน ปรอท

เทของเหลวลงในน้ำ จะลอยหรือจม

ความถ่วง API (API Gravity) ของน้ำมันปิโตรเลียม

สถาบันปิโตรเลียมของอเมริกา (American Petroleum Institute) กำหนดความถ่วงจำเพาะอีกแบบหนึ่งสำหรับน้ำมันปิโตรเลียมโดยเฉพาะ เรียกว่า "ความถ่วงเอพีไอ" (API Gravity) กำหนดให้น้ำ (s.g. = 1.000) มีความถ่วง API = 10

API Gr. = 141.5s.g. − 131.5
s.g. ที่ใช้แทนค่าต้องเป็นความถ่วงจำเพาะที่อุณหภูมิ 60 °F (15.6 °C) · ตรวจสอบ: s.g. = 1.000 → 141.5 − 131.5 = 10 ✔
สังเกต: s.g. อยู่ในส่วน ค่า API จึงกลับด้าน API ยิ่งมาก น้ำมันยิ่งเบา

🧮 แปลง s.g. ↔ ความถ่วง API

ความรู้เพิ่มเติม (ไม่อยู่ในหนังสือ): วงการน้ำมันแบ่งน้ำมันดิบตามความถ่วง API เช่น มากกว่า 31.1 = น้ำมันดิบเบา, 22.3–31.1 = ปานกลาง, น้อยกว่า 22.3 = หนัก น้ำมันดิบเบามีราคาสูงกว่า เพราะกลั่นเป็นน้ำมันเบนซินและดีเซลได้มากกว่า

เครื่องคิดเลขแปลงคุณสมบัติทั้ง 5 ค่า

รู้ค่าใดค่าหนึ่ง ก็หาค่าที่เหลือได้หมด เพราะทุกค่าเชื่อมกันด้วย ρ

🧮 รู้ 1 ค่า หาอีก 4 ค่า

ตัวอย่าง 4.1

ถังใบหนึ่งบรรจุน้ำมันหล่อลื่นมวล 460 kg และมีปริมาตร 500 Litre จงคำนวณหา 1. ความหนาแน่น 2. น้ำหนักจำเพาะ 3. ปริมาตรจำเพาะ 4. ความถ่วงจำเพาะ

ดูวิธีทำ
แปลงหน่วยก่อน: V = 500 Litre = 500 × 10⁻³ m³ = 0.5 m³
1. ρ = m/V = 460 / (500 × 10⁻³) = 920 kg/m³
2. γ = w/V = (460 × 9.81) / (500 × 10⁻³) = 9,025.2 N/m³
3. VS = V/m = (500 × 10⁻³) / 460 = 1.087 × 10⁻³ m³/kg
4. s.g. = ρf/ρw = 920 / 1,000 = 0.92

ตัวอย่าง 4.2

น้ำมันเชื้อเพลิงชนิดหนึ่ง มีความถ่วงจำเพาะ 0.71 จงคำนวณหา 1. ความหนาแน่น 2. น้ำหนักจำเพาะ 3. ปริมาตรจำเพาะ

ดูวิธีทำ
1. จาก s.g. = ρf/ρw → ρf = (s.g.)ρw = (0.71)(1,000) = 710 kg/m³
2. จาก s.g. = γf/γw → γf = (s.g.)γw = (0.71)(9,810) = 6,965.1 N/m³
3. VS = 1/ρ = 1/710 = 1.41 × 10⁻³ m³/kg

👀 เคล็ดลับการอ่านกระบอกตวงผิวของเหลวในกระบอกตวงโค้งลง เรียกว่า เมนิสคัส (meniscus) ให้อ่านที่ท้องโค้ง และให้สายตาอยู่ระดับเดียวกับผิวของเหลว ถ้ามองจากด้านบนหรือด้านล่าง จะอ่านค่าคลาดเคลื่อน (parallax)

ใบงาน 4

ตอนที่ 2 ทดสอบคุณสมบัติของไหลด้วยไฮโดรมิเตอร์

ไฮโดรมิเตอร์ (Hydrometer) เป็นหลอดแก้วถ่วงน้ำหนักที่ปลายล่าง ลอยตั้งตรงในของเหลว ของเหลวยิ่งหนาแน่น ไฮโดรมิเตอร์ยิ่งลอยสูง (จมน้อย) ตัวเลขที่ผิวของเหลวตัดกับก้านคือค่า s.g. ที่อ่านได้ทันที ไม่ต้องชั่งหรือตวง

อุปกรณ์และหลักการ

  1. ไฮโดรมิเตอร์ชนิดเบากว่าน้ำ ของจริงในห้องเป็นรุ่นภาษาจีน มี 2 สเกล: 比重 (ความถ่วงจำเพาะ) 0.700–1.000 และ 度 (องศาโบเม่ °Bé) 70–10
  2. กระบอกตวง ขนาด 100 ml จำนวน 3 ใบ
  3. ของเหลวสำหรับทดลอง จำนวน 3 ชนิด

สเกล 比重 ตัวเลขมากอยู่ด้านล่าง น้อยอยู่ด้านบน (กลับกับไม้บรรทัด) ช่องห่างไม่เท่ากัน ส่วนสเกล 度 ตัวเลขมากอยู่ด้านบน (70 ตรงกับ 0.700 และ 10 ตรงกับ 1.000 คือน้ำ) ช่องห่างเท่ากัน

สเกล 度 คือองศาโบเม่ °Bé = 140/s.g. − 130 ไม่ใช่ความถ่วง API แต่ค่าใกล้กันมาก (เช่น s.g. 0.800 ได้ 45.0 °Bé ส่วน API = 45.4) ใบงานต้องการค่า API จึงให้อ่าน s.g. แล้วคำนวณ API ด้วยสูตร API = 141.5/s.g. − 131.5

แบบฝึกหัดบทที่ 4 ตอนที่ 2 ลองทำในกระดาษก่อน แล้วค่อยกดดูเฉลย ตัวเลขทุกข้อตรวจสอบด้วยการคำนวณซ้ำแล้ว

ข้อ 1

น้ำมันชนิดหนึ่งมวล 170 kg มีปริมาตร 200 Litre จงหาความถ่วงจำเพาะของน้ำมันชนิดนี้

ดูเฉลย
ต้องหา ρ ก่อน: ρ = m/V = 170 / (200 × 10⁻³) = 850 kg/m³
s.g. = ρf/ρw = 850 / 1,000 = 0.85
เพิ่มเติม: ความถ่วง API = 141.5/0.85 − 131.5 = 34.97

ข้อ 2

ทดสอบของเหลวชนิดหนึ่ง โดยนำของเหลวปริมาตร 50 ml ไปชั่ง พบว่ามีมวล 75 g จงคำนวณหา 2.1 ความหนาแน่น 2.2 น้ำหนักจำเพาะ 2.3 ปริมาตรจำเพาะ 2.4 ความถ่วงจำเพาะ

ดูเฉลย
แปลงหน่วย: m = 75 g = 75 × 10⁻³ kg · V = 50 ml = 50 × 10⁻⁶ m³
2.1 ρ = (75 × 10⁻³)/(50 × 10⁻⁶) = 1,500 kg/m³
2.2 γ = ρg = (1,500)(9.81) = 14,715 N/m³
2.3 VS = 1/ρ = 1/1,500 = 6.67 × 10⁻⁴ m³/kg
2.4 s.g. = 1,500/1,000 = 1.5 (หนักกว่าน้ำ จึงใช้ไฮโดรมิเตอร์ชนิดเบากว่าน้ำวัดไม่ได้)

ข้อ 3

วัดความถ่วงจำเพาะของน้ำมันเชื้อเพลิงชนิดหนึ่งด้วยไฮโดรมิเตอร์ ได้ 0.81 จงคำนวณหา 3.1 ความหนาแน่น 3.2 น้ำหนักจำเพาะ 3.3 ปริมาตรจำเพาะ

ดูเฉลย
3.1 ρf = (s.g.)ρw = (0.81)(1,000) = 810 kg/m³
3.2 γf = (s.g.)γw = (0.81)(9,810) = 7,946.1 N/m³
3.3 VS = 1/ρ = 1/810 = 1.23 × 10⁻³ m³/kg
